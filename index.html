Git Visualizer

SVG Interactive

インタラクティブにGitコマンドを打ち込み、ブランチツリーやコミットグラフがどのように動くかをビジュアルで学習できるシミュレータ。

Git学習 インタラクティブ Sandbox

  3. コミットツリーが動的に変化し、ブランチやHEADの概念をアニメーションで視覚的に学習できます。

GitHub API

OSSデータベース スター数比較 インフラ紹介

SVG Wave & Blob Generator

SVG Vector

有機的なアメーバ状Blobや滑らかな波形をパラメータ調整で簡単に出力できるデザイナー向けグラフィックツール。

SVG/PNGエクスポート アニメーション マルチレイヤー
💡 使い方を表示
  1. 「Shape Type」でBlob（アメーバ型）またはWave（波形型）を選択します。
  2. スライダーで頂点数（Complexity）やゆらぎの強さ（Growth）、カラー（単色/グラデーション）を調整します。
  3. 「Download SVG」でベクター素材を、「Export PNG」で画像を書き出します（Pro版でアニメーション化も可）。
ツールを起動する

JSON Schema Converter

JSON/YAML/XML

JSONのパース、バリデーションに加え、YAML、XML、CSVやTypeScript/Go言語の型定義コードへ瞬時に相互変換するツール。

データ変換 型定義生成 ダミー生成
💡 使い方を表示
  1. 左側の「Input JSON」エディタに、整形または変換したいJSONデータを貼り付けます（エラーがあれば自動で赤色警告）。
  2. 「Convert To」セレクトボックスから、YAML/XML/CSVや型定義（TypeScript/Go/Java）を選択します。
  3. 「Convert Data」ボタンをクリックすると、右側のエディタに変換結果が高速出力されます。

Regex Playground

Regex Real-time

正規表現をリアルタイムにマッチハイライトし、その文法構造を分かりやすくステップバイステップで分解解説するPlaygroundツール。

正規表現テスト マッチハイライト AIモック生成
💡 使い方を表示
  1. 「Expression Pattern」に正規表現を、「Test String」にテストしたい文章を入力します（テンプレート利用も可）。
  2. テスト文字列内のマッチした部分がリアルタイムで黄色くハイライトされ、一致件数がバッジで表示されます。
  3. Pro版をアンロックすると、正規表現を細かく分解した日本語解説や、自然言語からのパターン自動生成が使えます。
ツールを起動する

Web SFX Generator

Web Audio API

正弦波・矩形波・三角波等のシンセサイザー音波やマイク録音をサンプリングし、ピッチやエコー等を自由に加工してSEを作成・WAV保存できるツール。

シンセ・録音 エフェクト加工 WAV出力
💡 使い方を表示
  1. 音源タイプ（シンセサイザーの波形、または「マイク録音」）を選択し、ベース音を入力または録音します。
  2. スライダーで周波数、ADSR、ピッチ（音程・速度）、エコー（ディレイ）、フィルター、ディストーションを調整します。
  3. 「再生」で試聴し、気に入ったら「Download WAV」でSEファイルを書き出します（ランダムSE合成も可能）。
ツールを起動する

Git Visualizer

コマンド入力でブランチツリーを視覚的に学ぶサンドボックス

ガイドレッスン

  • 1. 基本的なコミット

    commitコマンドで歴史を作ります。

  • 2. ブランチの作成

    checkoutで新ブランチを作り分岐します。

  • 3. マージ (Merge)

    mainブランチに開発内容を統合します。

  • 4. リベース (Rebase) ⭐

    分岐元の履歴を最新状態の先に再配置します。

コマンドリファレンス

git commit
git branch [名]
git checkout [名]
git merge [名]
git rebase [名]
※コマンドをクリックすると入力欄に入力されます。
